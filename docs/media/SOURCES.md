# Preview provenance

This gallery uses screenshots already saved in the project `previews/` directory. It shows the 3D study room, pooled distribution comparison, sensitivity analysis and closing scene. The closing screenshot has only its surrounding letterbox borders removed. The original scene content, labels and values are unchanged.

`Reaction-Time-Scene-Gallery.mp4` is a 22.2-second crossfade slideshow made from those four screenshots, at 1280 × 720 / 30 fps, with no audio. It is a scene gallery, not a fresh recording of the current typography, dance or page-transition timing. Some saved screenshots predate the final motion revisions.

The browser security policy blocked opening the local HTML during this update; no alternate browser, protocol, automation surface or HTML renderer was used to bypass it. Use the final HTML release to experience the current interactive animations.

Existing project attribution continues to apply. Source references, crops and hashes are in `manifest.json`.

## Animated character preview

`character-motion.gif` is the project's saved full-body motion capture (`previews/fullbody-motion.gif`), 831 × 467, 103 frames, 11.2 seconds. It shows sitting, standing and bowing. It is an archived development capture; some typography and slide numbering predate the final deck. It is genuine scene motion, not a crossfade slideshow. No new browser capture was made.
